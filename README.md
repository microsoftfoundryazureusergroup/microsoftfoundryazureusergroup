# Microsoft Foundry & Azure User Group

Microsoft Foundry & Azure User Group is a community for builders, cloud engineers, AI practitioners, startup teams, and technology enthusiasts who want to learn, share, and grow with Microsoft technologies.

We bring people together to explore Microsoft Foundry, Azure, cloud-native architecture, AI application development, observability, integrations, and practical implementation patterns through community-driven learning.

## At a Glance

- Community base: Rotterdam, Netherlands
- Event format: Online and in-person sessions
- Core themes: Microsoft Foundry, Azure, AI, cloud architecture, and developer enablement
- Community style: Knowledge sharing, practical learning, and professional networking

## What We Do

- Host live sessions, workshops, technical talks, and networking events
- Share practical knowledge on Microsoft Foundry, Azure services, and modern developer workflows
- Create space for beginners and experienced practitioners to learn from each other
- Discuss real-world use cases, best practices, and architecture patterns
- Build a supportive network around cloud, AI, and Microsoft ecosystem innovation

## Community Focus

Our sessions are designed for people who want hands-on insight into topics such as:

- Microsoft Foundry and intelligent application development
- Azure architecture and cloud platform services
- AI engineering and production-ready workflows
- API integrations, automation, and orchestration
- Observability, reliability, and scalable solution design

## Who This Community Is For

This user group welcomes:

- Developers and software engineers
- Cloud architects and DevOps professionals
- AI builders and solution designers
- Startup founders and technical teams
- Students, learners, and career switchers exploring Microsoft technologies

Whether you are just getting started with Azure or already building advanced solutions, the community is intended to help you deepen your skills, stay current, and connect with others doing similar work.

## How We Engage

We run a mix of online and community events that encourage learning and connection. Recent topics and event themes have included Microsoft Foundry, Azure Skills, observability, AI gateways, and Microsoft Build local community engagement.
